    udns: update to 0.7
    
    udns is maintained again: 0.5 (March 2024) and 0.6 (July 2024) were the
    first releases in ten years, and 0.7 followed in October 2026.
    
    0.7 fixes several bugs in DNS name parsing, among them a heap buffer
    overflow: a reply whose first name contained a compression pointer
    made dns_stdrr_size() undersize a buffer that dns_stdrr_finish()
    then wrote past. It also fixes dns_cancel() leaking the cancelled
    query.
    
    0.5 and 0.6 fix repeated queries for non-existing domains and the
    inet_ntop()/inet_pton() checks, among others.
    
    The autotools patch only needs its AC_INIT version bumped; the set of
    source files is unchanged.
    
    Release notes: https://www.corpit.ru/mjt/udns/NEWS
